# Career Recommendation System using Machine Learning

The Career Recommendation System using Machine Learning is an AI-based project designed to assist individuals in making informed career decisions based on their skills and aptitude.

**Project Name:** Career Recommendation System using Machine Learning  
**PS Code:** SIH1434  


## Project Overview

Choosing a suitable career path is often challenging due to the wide range of options and lack of personalized guidance. This project applies machine learning techniques to analyze student skill and aptitude data and recommend appropriate career paths.

The system focuses on data preprocessing, feature selection, model training, and performance evaluation using supervised machine learning algorithms.


## Purpose

The main purpose of this project is to provide data-driven career recommendations using machine learning. By analyzing skill-based inputs, the system helps reduce confusion and supports confident career decision-making.


## Goal

- Build a machine learning model for career prediction  
- Analyze aptitude and skill data  
- Evaluate model performance using accuracy and classification metrics  
- Demonstrate practical application of machine learning in career guidance  


## Problem It Solves

Traditional career guidance systems often provide generic advice and do not consider individual skill sets. This project addresses the issue by offering personalized career recommendations based on structured data and machine learning analysis.


## Significance

This project highlights the application of machine learning in the education and career counseling domain. It demonstrates how AI-driven systems can support informed decision-making and career planning.


## Tech Stack

- **Python**
- **Pandas**
- **NumPy**
- **Scikit-learn**
- **Jupyter Notebook**


## Project Features

- Skill-based data preprocessing  
- Label encoding for career categories  
- Random Forest classification model  
- Train-test data splitting  
- Model evaluation using accuracy and classification report  
- Aptitude and career data visualization  


## How It Works

1. Student aptitude and skill data is loaded from a structured dataset.  
2. Data preprocessing and feature selection are performed.  
3. Labels are encoded for machine learning compatibility.  
4. A Random Forest classifier is trained on the dataset.  
5. Model performance is evaluated using accuracy and classification metrics.  


## Challenges and Solutions

**Data Quality and Preprocessing**  
Challenge: Ensuring clean and structured input data.  
Solution: Applied preprocessing and encoding techniques to standardize the dataset.

**Prediction Accuracy**  
Challenge: Achieving reliable predictions across multiple career categories.  
Solution: Used Random Forest classifier and evaluated results using classification reports.
